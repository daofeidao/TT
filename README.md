# TT 终端

TT 是面向 iPhone 的轻量终端测试项目，优先保证 iOS 15 兼容和实际设备上的交互体验。

## 当前开发版（v0.3.0 测试中）

- 保留 TT 专属应用图标、中文界面、清空终端和输入历史。
- 使用原生 iOS 文本视图支持长按选择、拖动选区手柄和复制。
- 尝试通过设备的 `/bin/sh` 执行输入的命令，并显示标准输出、错误输出和退出码。
- 如果 iOS 环境拒绝启动 Shell，会在终端中显示明确错误，不会把输入回显伪装成命令执行成功。
- 推荐先测试：`pwd`、`ls`、`whoami`、`uname -a`、`date`。

## 重要说明

v0.3.0 是命令执行链路的验证版本。能否在目标设备上启动 `/bin/sh`，取决于 iOS 系统路径、进程创建限制和 TrollStore 安装环境，必须以实际设备结果为准。当前实现会为每条输入启动一次 Shell 进程；它还不是带有持久会话状态的完整交互式 PTY 终端，因此例如 `cd` 的目录变化不会自动保留到下一条命令。

## 获取安装包

打开仓库的「发行版（Releases）」页面下载已发布版本。开发分支的构建产物可在 GitHub Actions 对应运行记录中下载。

## 兼容性与构建

- 最低部署版本：iOS 15.0
- 界面：SwiftUI + UIKit 文本选择视图
- Xcode 项目：由 `project.yml` 自动生成
- 编译平台：GitHub Actions 的 macOS 云端环境
- 安装：用于 TrollStore 测试；是否可安装、能否启动 Shell，均需在目标 iPhone 上实际验证。

## 仓库目录说明

- `TT/`：应用界面与入口代码
- `TT/Assets.xcassets/`：应用图标资源
- `scripts/`：生成图标的脚本
- `.github/workflows/`：自动编译与发行版发布流程
